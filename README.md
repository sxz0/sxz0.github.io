# pedromiguel.me

Personal academic website of **Pedro Miguel Sánchez Sánchez** — Data Scientist and Researcher (AI, Federated Learning, Cybersecurity, Recommender Systems). Live at <https://pedromiguel.me>.

Built with [Jekyll](https://jekyllrb.com/) on top of the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (a fork of Minimal Mistakes) and hosted on GitHub Pages.

## Structure

| Path | Content |
|---|---|
| `_config.yml` | Site settings, author profile/social links, SEO, collections |
| `_data/navigation.yml` | Top menu |
| `_pages/` | Home (`about.md`), CV, PhD thesis, publications, talks and archive pages |
| `_publications/` | One Markdown file per paper (front matter: `category` = `manuscripts` or `conferences`, `venue`, `paperurl`, `citation`) |
| `_talks/` | One Markdown file per talk/tutorial |
| `_posts/` | Blog posts (news, awards) |
| `files/` | CV PDF and PhD thesis PDF, served at `/files/...` |
| `images/` | Profile photo, post images, favicons |
| `_layouts/`, `_includes/`, `_sass/`, `assets/` | Theme code (rarely needs editing) |
| `markdown_generator/` | Scripts to generate publication/talk files from TSV or BibTeX |
| `talkmap.py`, `talkmap/` | Talk location map, regenerated by `.github/workflows/scrape_talks.yml` when `_talks/` changes |

## Updating content

- **New paper:** copy an existing file in `_publications/`, edit the front matter and paste the abstract as the body.
- **New talk:** add a file to `_talks/` following the existing ones.
- **New post:** add `_posts/YYYY-MM-DD-title.md`.
- **CV:** edit `_pages/cv.md` and replace `files/CV_Pedro_Miguel_Sanchez.pdf`.
- **h-index:** change `h_index` in `_config.yml`; it updates the CV and Publications pages.
- **SEO/analytics:** fill `google_site_verification` / `bing_site_verification` and `analytics` in `_config.yml`. `robots.txt` and the sitemap (`jekyll-sitemap`) are already set up.

## Running locally

With Ruby and Bundler installed:

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open <http://localhost:4000>. Restart the server after editing `_config.yml`.

Alternatively, use Docker (`docker compose up`) or the VS Code dev container in `.devcontainer/`.
